Features

What's inside the app

Six tools that cover a typical school week. Everything runs locally — the app doesn't need a server to work.

Class schedule

Add your classes once — see each day's times and rooms at a glance, plus what's coming next.

Task & exam tracker

List assignments and exams with due dates, then check them off. Overdue items stay on top until handled.

Offline AI tutor

Ask study questions and get explanations with no connection — on commutes, in dorms, in dead zones. Questions never leave the phone.

Notes per subject

Write and organize notes by subject. Stored on your device and searchable, so they're there whenever class starts.

Grades & GPA

Enter grades as they come in and see your running GPA per semester and overall, computed on-device.

Local reminders

Notifications before classes and deadlines, scheduled directly on the device. No server, no push service.

Worth knowing before you install

  • Updating from v1.0.0? Android will refuse the install because this release is signed with a new key. Uninstall the old version first — local data (notes, grades) will be erased, so export anything you need.
  • This is a direct APK release, not a Play Store listing. When installing, allow your browser to install apps if Android asks.
  • If Google Play Protect flags the app as from an unknown developer, that's expected for any sideloaded APK — the build is signed with the official SchedMate release key.
  • Your data is stored locally. Uninstalling the app deletes it, so keep device backups if the notes matter to you.
  • The APK is served from GitHub Releases (CDN). If the download is slow, you can also grab any version from the Releases page.
